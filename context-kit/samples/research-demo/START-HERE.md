# Hi Alex — meet Mira.

This folder gives Mira a lasting memory for **Sleep and Learning**. It keeps your project's notes and working rules together, so you do not have to explain everything again each time.

## 2. Put this folder in the right place

- **Starting a new project?** This folder is your project. Keep it wherever you want to work.
- **Already have a project?** Copy everything inside this folder into your project's main folder. If you already have an `AGENTS.md` or `CLAUDE.md`, paste the contents of ours at the bottom of yours.

## 3. Start Mira

### Claude Code

For first-time setup, install Claude Code from claude.com/claude-code. Open the Terminal app, type `cd ` (with a space), drag this folder into the window, and press Enter. Type `claude`, press Enter, and say "hi".

Mira will welcome you and ask a few questions to finish setup.

### Cursor

For first-time setup, install Cursor from cursor.com. Choose File → Open Folder, pick this folder, open the chat, and say "hi".

Mira will welcome you and ask a few questions to finish setup.

### Another AI tool

Open this folder in your AI tool and say "read AGENTS.md".

Mira will welcome you and ask a few questions to finish setup.

## 4. A typical session

1. Say hi.
2. Tell Mira what you want to do.
3. Say **"save"** before you close.

## 5. Everyday phrases

- Say "save" (or type /save)
- Say "set up" (or type /setup)
- Say "ingest" (or type /ingest)
- Say "ask …" (or type /ask)
- Say "health check" (or type /lint)

## 6. What's in this folder

- `AGENTS.md` tells your AI how to work with you.
- `context/` holds the current state, decisions and a simple activity log.
- `.claude/` and `.cursor/` hold shortcuts for the tools you selected.

## 7. Research with Mira

1. Put PDFs, saved articles, datasets, images, notes or transcripts in `raw/`.
2. Say **"ingest"**. Mira will read up to five sources at a time and build linked notes in `wiki/`.
3. Ask a question. Answers use your sources and show where each claim came from.
4. Find longer reports, slides and charts in `outputs/`.

For saved web pages, you can use Obsidian Web Clipper and set its save location to `raw/`.

Open this folder as an Obsidian vault:
1. Install Obsidian from obsidian.md.
2. Open Obsidian and choose **Open folder as vault**.
3. Pick this project folder.

## 8. If Mira seems to forget things

Say **"read AGENTS.md and context/state.md"**, then say **"save"** when the notes are up to date.
